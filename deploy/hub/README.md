# Хаб-оглавление учебных сайтов

Живёт в `/var/www/duckdns-root/` (`hub.js` + `hub.json`), здесь — резервная копия.

- **Добавить проект в оглавление**: одна запись в `hub.json` (path/emoji/name/desc).
- **Подключить хаб на новом сайте**: одна строка перед `</body>`:
  `<script src="/hub.js" defer></script>`
  (или nginx `sub_filter`, как у relmet/reduktor — тогда репозиторий сайта не трогается).
- Пути относительные — переезд домена переживает; при автономном запуске сайта
  из репы скрипт молча не грузится, сайт работает как ни в чём не бывало.
- Треки (/map/) и мониторинг (/monitor/) в оглавление не включаем.
